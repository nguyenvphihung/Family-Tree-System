
  # Map Feature Design

  This is a code bundle for Map Feature Design. The original project is available at https://www.figma.com/design/fVy9OjMkA1cRsoa9SUcVIl/Map-Feature-Design.

  ## Running the code

  From root dir run `cd backend` and `mvn spring-boot:run` to start BE.

  From root dir run `cd frontend` and `npm i` to install the dependencies.

  From root dir run `npm run dev` to start FE.
